# Книга 3: Что уже встроено в MX

Секрет MX в том что почти ничего не надо подключать рукаами. Текст, числа, файлы, сеть,
графика и даже 3D — всё уже есть внутри. Тут я расписал основные возмоности с примерами,
чтобы ты не искал готовые решения и не изобретал велосипед.

## Сеть

### HTTP-клиент

MX умеет слать запросы и получать ответы. Самое полезное — клиент, посмотри пример ниже.

```mx
let ответ = Http.get("http://example.com/")
if ответ.ok() {
    System.println(ответ.body)
}
let код = ответ.status
let заголовок = ответ.header("Server")

let ответ2 = Http.post("http://api.example.com/form", "имя=Саша")
let ответ3 = Http.postJson("http://api.example.com/users", "{\"имя\":\"Саша\"}")
```

### HTTP-сервер

```mx
func main(): int {
    let сервер = HttpServer.create(8080)
    loop {
        let запрос = сервер.accept()
        if запрос.valid == false { continue }
        if String.equals(запрос.path(), "/") {
            сервер.replyHtml(запрос, 200, "<h1>Привет!</h1>")
        } else {
            сервер.notFound(запрос)
        }
    }
    return 0
}
```

## Графика (Gfx)

```mx
func main(): int {
    let окно = Gfx.open(640, 480, "Моя игра")

    while Gfx.isOpen(окно) {
        Gfx.clear(окно, 30, 30, 60)
        Gfx.fillCircle(окно, 320, 240, 50, 255, 0, 0)
        Gfx.rect(окно, 50, 50, 100, 80, 0, 255, 0)
        Gfx.line(окно, 0, 0, 640, 480, 255, 255, 255)
        Gfx.text(окно, 10, 10, "Привет из MX!")

        let событие = Gfx.pollEvent(окно)
        if событие == 3 { break }   // 3 = закрытие окна

        Gfx.show(окно)
    }

    Gfx.close(окно)
    return 0
}
```

Коды событий `Gfx.pollEvent` (это число которое возвращает функция):

| Код | Что |
|---|---|
| 0 | ничего |
| 1 | клавиша |
| 2 | клик мыши |
| 3 | окно закрыли |
| 4 | перетаскивание |
| 6 | отпустили кнопку |
| 7 | колесо |

## Чего пока нет

Честно про ограничения (их мало, но знать надо, чтобы не удивляться):

- **HTTPS не поддерживается** встроенным HTTP-клиентом (нет TLS). `https://` вернёт -1.
- `File.watch` (слежение за файлами) работает только в байткоде, не в exe.
