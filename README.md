# Документация MX

Собрал тут всё про язык MX простым языком. Четыре книги:

1. **01_ЯЗЫК_И_РУКОВОДСТВО.md** — что такое MX, как поставить и запустить первую программу.
2. **02_СИНТАКСИС.md** — как писать код: переменные, условия, циклы, функции, классы.
3. **03_СТАНДАРТНАЯ_БИБЛИОТЕКА.md** — что уже встроено: текст, файлы, сеть, графика, 3D.
4. **04_ПРИМЕРЫ_ПРОГРАММ.md** — готовые программы, запускай и дорабатывай.

С чего начать: сначала 01 (установка), потом 02 (основы), потом смотри 04 с примерами.
Справочник всех возможностей — в 03.

Ещё в проекте:
- **editors/vscode-mx/** — расширение для VS Code.
- **installer/** — инсталлеры для Windows и Linux.
- **docs/ui/** — веб-интерфейс.
