## Переменные

Переменная это ящик с именем, в котором лежит значение. Указывешь тип (что внутри) и имя.

```mx
let возраст: int = 25
let имя: str = "Маша"
let рост: float = 1.72
let живой: bool = true
```

Три слова для объявления:

| Слово | Смысл |
|---|---|
| `let` | не будешь менять значение (лучше по умолчанию) |
| `var` | будешь менять |
| `const` | константа, значение известно сразу и не меняется |

```mx
var счётчик: int = 0
счётчик = счётчик + 1

const ЧИСЛО_ПИ: float = 3.14
ЧИСЛО_ПИ = 3.0        // ошибка! константу нельзя менять
```

Тип можно не писать — MX сам поймёт:

```mx
let x = 42        // сам понял что это int
let s = "привет"  // сам понял что это str
```

## Типы

| Тип | Что хранит | Пример |
|---|---|---|
| `int` | целое число | `42`, `-7` |
| `float` | дробное | `3.14` |
| `bool` | правда/ложь | `true`, `false` |
| `str` | текст | `"привет"` |
| `char` | один символ | `'A'` |

### Массивы

```mx
let числа: [int] = [10, 20, 30]
let первый = числа[0]        // 10, счёт с нуля
числа[1] = 99                // поменяли второй
let сколько = len(числа)     // 3
```

### Списки и словари

```mx
let список: List[str] = List[str].new()
List[str].push(список, "один")
List[str].push(список, "два")
let первый = List[str].get(список, 0)   // "один"

let словарь: Map[str, int] = Map[str, int].new()
Map[str, int].set(словарь, "яблоко", 5)
let сколько = Map[str, int].getOr(словарь, "яблоко", 0)   // 5
```

## Функции

Функция это блок кода с именем, который можно вызывать сколко угодно раз.

```mx
func сложить(a: int, b: int): int {
    return a + b
}

func поздороваться(имя: str): str {
    return "Привет, " + имя + "!"
}
```

- `func` — ключевое слово
- `сложить` — имя
- `(a: int, b: int)` — параметры с типами
- `: int` — что возвращает
- `return` — вернуть результат

Вызов:

```mx
let сумма = сложить(2, 3)       // 5
System.println(поздороваться("Саша"))
```

Если функция ничего не возвращает, пишем `void`:

```mx
func напечатать(текст: str): void {
    System.println(текст)
}
```

## Условия

`if` — если, `else` — иначе, `else if` — иначе если.

```mx
if балл >= 90 {
    System.println("Отлично!")
} else if балл >= 70 {
    System.println("Хорошо")
} else {
    System.println("Попробуй ещё раз")
}
```

Полезные штуки:

```mx
unless пауза {          // если НЕ пауза
    двигать()
}

guard длина(данные) > 0 else {   // иначе выйти
    return -1
}
```

`guard` удобен когда надо убедиться что условие выполненно, иначе выходим.

## Циклы

```mx
let i: int = 0
while i < 5 {
    System.println(i)
    i = i + 1
}

for (let k: int = 0; k < 10; k = k + 1) {
    System.println(k)
}

for (let число in числа) {     // перебор массива
    System.println(число)
}

repeat 3 {                     // повторить 3 раза
    System.println("пинг")
}

loop {                          // бесконечный, выход через break
    let событие = Gfx.pollEvent(окно)
    if событие == 3 { break }
}
```

`break` — выйти из цикла. `continue` — к следующему шагу (пропускает остаток тела).

## Классы

Класс описывает «вещь»: у неё есть данные (свойства) и действия (методы).

```mx
class Игрок {
    имя: str
    здоровье: int

    func init(имя: str) {
        this.имя = имя
        this.здоровье = 100
    }

    func ударить(урон: int): void {
        this.здоровье = this.здоровье - урон
    }

    func жив(): bool {
        return this.здоровье > 0
    }
}
```

`this` — «я сам». `init` — конструктор, вызывается при создании.

```mx
let герой = new Игрок("Артур")
герой.ударить(30)
if герой.жив() {
    System.println(герой.имя + " ещё жив!")
}
```

### Наследование

```mx
class Персонаж {
    имя: str
    func init(имя: str) { this.имя = имя }
    func говорить(): void { System.println("Я " + this.имя) }
}

class Маг : Персонаж {
    мана: int
    func init(имя: str, мана: int) {
        super.init(имя)          // родительский конструктор
        this.мана = мана
    }
    func колдовать(): void { System.println("Абракадабра!") }
}
```

## Интерфейсы

Интерфейс описывает какие методы должен иметь класс, но не говорит как они устроены.

```mx
interface Рисуемый {
    func нарисовать(): void
}

class Круг : Рисуемый {
    func нарисовать(): void {
        System.println("Рисую круг")
    }
}
```

## Дженерики

Код, который работает с любым типом.

```mx
func первыйЭлемент<T>(список: [T]): T {
    return список[0]
}

let a = первыйЭлемент([1, 2, 3])   // int
let b = первыйЭлемент(["x", "y"])  // str
```

Можно ограничить тип:

```mx
func найтиМакс<T : Сравнимый>(список: [T]): T {
    let макс = список[0]
    return макс
}
```

## Ошибки

### try / catch

```mx
try {
    throw "что-то пошло не так"
} catch (сообщение) {
    System.println("Ошибка: " + сообщение)
}
```

### panic — остановиться

```mx
func делить(a: int, b: int): int {
    if b == 0 {
        panic("Нельзя делить на ноль!")
    }
    return a / b
}
```

### defer — «не забудь при выходе»

```mx
func открытьКартинку(): void {
    let окно = Gfx.open(640, 480, "Картинка")
    defer {
        Gfx.close(окно)   // закроется даже если что-то упадёт
    }
}
```

## Асинхронность

`async` запускает задачу в фоне, `await` ждёт результат.

```mx
async func скачатьДанные(): str {
    return "данные"
}

func main(): int {
    let задача = async скачатьДанные()
    let результат = await задача
    System.println(результат)
    return 0
}
```

## Память и unsafe

MX сам следит за памятью: проверяет границы массивов, собирает мусор. Прямая работа с
памятью — редкий случай, только в `unsafe` и с особым флагом:

```mx
unsafe {
    let указатель = Memory.alloc(1024)
    Memory.writeU8(указатель + 0, 255)
    let значение = Memory.readU8(указатель + 0)
    Memory.free(указатель)
}
```
